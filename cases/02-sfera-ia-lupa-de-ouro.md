# SFERA IA: agentes de IA para a força de vendas (50º Prêmio Lupa de Ouro)

> Projeto da Zambon com participação da Ottorise. **Vencedor do 50º Prêmio Lupa de Ouro (Sindusfarma, nov/2026)** na categoria Melhor Projeto de Inteligência de Mercado / Produtividade e Efetividade.

**Contexto.** A força de vendas precisava de respostas rápidas sobre dados comerciais sem depender de alguém montando relatório sob demanda.

**Meu papel no time**
- Integrante do time que construiu os **agentes de IA no Copilot Studio** sobre os dados do **Fabric**.
- Os agentes usam a mesma base de dados do [lakehouse comercial](01-fabric-lakehouse-farma.md).

**Por que é relevante.** Mostra a ponte entre engenharia de dados e IA generativa: o agente só responde bem quando a camada gold está limpa, modelada e governada.

**Stack:** Copilot Studio · Microsoft Fabric · Power BI · Power Platform
